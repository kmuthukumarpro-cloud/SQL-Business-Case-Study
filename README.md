# Dataset

The project uses a simple sales data warehouse structure with three tables.

## fact_sales

This is the main transaction table and contains sales information.

| Column | Description |
|---|---|
| `customer_key` | Unique customer identifier |
| `order_number` | Unique order identifier |
| `product_key` | Unique product identifier |
| `sales_amount` | Revenue generated from the transaction |
| `order_date` | Date of the transaction |

## dim_customers

Contains customer information.

| Column | Description |
|---|---|
| `customer_key` | Unique customer identifier |
| `first_name` | Customer first name |
| `last_name` | Customer last name |
| `country` | Customer country |

## dim_products

Contains product information.

| Column | Description |
|---|---|
| `product_key` | Unique product identifier |
| `product_name` | Product name |

### Data Grain

`fact_sales` contains transaction-level sales records.

Because of this:

- Revenue is calculated using `SUM(sales_amount)`
- Customers are counted using `COUNT(DISTINCT customer_key)`
- Orders are counted using `COUNT(DISTINCT order_number)`

# SQL Solutions

## 1. Total Revenue

### Business Question

Calculate the total revenue generated by the company.

```sql
SELECT
    SUM(sales_amount) AS total_revenue
FROM fact_sales;
```

Find the number of unique orders.

```sql
SELECT
```

## 4. Top Product

### Business Question

Identify the product generating the highest revenue.

```sql
SELECT TOP 1
    p.product_key,
    p.product_name,
    SUM(s.sales_amount) AS total_revenue
FROM fact_sales s
INNER JOIN dim_products p
    ON p.product_key = s.product_key
GROUP BY
    p.product_key,
    p.product_name
ORDER BY total_revenue DESC;
```

### What this query does

The sales table is joined with the product table so that the product name can be displayed.

The query groups the sales by product and calculates total revenue for each product.

`TOP 1` combined with `ORDER BY ... DESC` returns the product with the highest revenue.

## 5. Top Customer

### Business Question

Identify the customer generating the highest revenue.

```sql
SELECT TOP 1
    c.customer_key,
    CONCAT(c.first_name, ' ', c.last_name) AS customer_name,
    SUM(s.sales_amount) AS total_revenue
FROM fact_sales s
INNER JOIN dim_customers c
    ON c.customer_key = s.customer_key
GROUP BY
    c.customer_key,
    c.first_name,
    c.last_name
ORDER BY total_revenue DESC;
```

### What this query does

The sales table is joined with the customer table.

The query calculates total revenue for every customer and sorts the results from highest to lowest.

`TOP 1` returns the customer with the highest revenue.

## 6. Revenue by Country

### Business Question

Calculate total revenue generated in each country.

```sql
SELECT
    c.country,
    SUM(s.sales_amount) AS total_revenue
FROM fact_sales s
INNER JOIN dim_customers c
    ON c.customer_key = s.customer_key
GROUP BY c.country
ORDER BY total_revenue DESC;
```

### What this query does

The customer table provides the country information.

Revenue is grouped by country and sorted from highest to lowest.

## 7. Revenue by Month

### Business Question

Analyze monthly revenue trends.

```sql
SELECT
    YEAR(order_date) AS order_year,
    MONTH(order_date) AS order_month,
    SUM(sales_amount) AS total_revenue
FROM fact_sales
GROUP BY
    YEAR(order_date),
    MONTH(order_date)
ORDER BY
    order_year,
    order_month;
```

### What this query does

The year and month are extracted from `order_date`.

Revenue is then grouped by year and month to show how revenue changes over time.

## 8. Average Order Value

### Business Question

Calculate the average revenue generated per order.

```sql
SELECT
    SUM(sales_amount) * 1.0 /
    COUNT(DISTINCT order_number) AS avg_order_value
FROM fact_sales;
```

### Formula

Average Order Value = Total Revenue / Total Unique Orders

`* 1.0` is used so that the calculation returns a decimal value instead of integer division.

## 9. Customers Above Average Spend

### Business Question

Identify customers whose total spending is higher than the average customer spending.

```sql
WITH Customer_Total AS
(
    SELECT
        customer_key,
        SUM(sales_amount) AS total_spend
    FROM fact_sales
    GROUP BY customer_key
)
SELECT
    customer_key,
    total_spend
FROM Customer_Total
WHERE total_spend >
(
    SELECT AVG(total_spend)
    FROM Customer_Total
);
```

### What this query does

The CTE first calculates total spending for every customer.

The second part calculates the average customer spending and returns customers whose spending is above that average.

### What this query does

## 11. Rank Customers

### Business Question

Rank customers based on their total spending.

```sql
WITH Customer_Total AS
(
    SELECT
        customer_key,
        SUM(sales_amount) AS total_spending
    FROM fact_sales
    GROUP BY customer_key
)
SELECT
    customer_key,
    total_spending,
    RANK() OVER
    (
        ORDER BY total_spending DESC
    ) AS customer_rank
FROM Customer_Total;
```

### What this query does

First, total spending is calculated for every customer.

Then `RANK()` assigns a ranking based on total spending.

The customer with the highest spending receives rank 1.

## 12. Top 3 Products

### Business Question

Identify the top 3 products by revenue.

```sql
WITH Product_Revenue AS
(
    SELECT
        product_key,
        SUM(sales_amount) AS total_revenue
    FROM fact_sales
    GROUP BY product_key
),
Product_Rank AS
(
    SELECT
        product_key,
        total_revenue,
        RANK() OVER
        (
            ORDER BY total_revenue DESC
        ) AS product_rank
    FROM Product_Revenue
)
SELECT *
FROM Product_Rank
WHERE product_rank <= 3;
```

### What this query does

The first CTE calculates revenue for every product.

The second CTE ranks the products.

The final query returns products with a rank of 3 or less.

## 13. Running Total Revenue

### Business Question

Calculate cumulative revenue over time.

```sql
WITH Revenue_Total AS
(
    SELECT
        DATEFROMPARTS
        (
            YEAR(order_date),
            MONTH(order_date),
            1
        ) AS revenue_month,
        SUM(sales_amount) AS monthly_revenue
    FROM fact_sales
    GROUP BY
        DATEFROMPARTS
        (
            YEAR(order_date),
            MONTH(order_date),
            1
        )
)
SELECT
    revenue_month,
    monthly_revenue,
    SUM(monthly_revenue)
    OVER
    (
        ORDER BY revenue_month
    ) AS running_revenue
FROM Revenue_Total;
```

### What this query does

The CTE first calculates revenue for every month.

The window function then adds each month's revenue to the previous total to produce a running total.

## 14. Monthly Growth Analysis

### Business Question

Compare monthly revenue with the previous month.

```sql
WITH Current_Month AS
(
    SELECT
        DATEFROMPARTS
        (
            YEAR(order_date),
            MONTH(order_date),
            1
        ) AS revenue_month,
        SUM(sales_amount) AS monthly_revenue
    FROM fact_sales
    GROUP BY
        DATEFROMPARTS
        (
            YEAR(order_date),
            MONTH(order_date),
            1
        )
),
Previous_Month AS
(
    SELECT
        revenue_month,
        monthly_revenue,
        LAG(monthly_revenue)
        OVER
        (
            ORDER BY revenue_month
        ) AS previous_month_revenue
    FROM Current_Month
)
SELECT
    revenue_month,
    monthly_revenue,
    previous_month_revenue,
    ROUND(
        COALESCE(
            (monthly_revenue - previous_month_revenue) * 100.0
            / NULLIF(previous_month_revenue, 0),
            0
        ),
        2
    ) AS growth_pct
FROM Previous_Month;
```

### What this query does

The first CTE calculates monthly revenue.

`LAG()` gets the previous month's revenue.

The final calculation determines the percentage change between the current month and the previous month.

### Formula

Growth % = (Current Month Revenue - Previous Month Revenue) / Previous Month Revenue × 100

## 15. Revenue Contribution Percentage

### Business Question

Calculate each product's contribution to total company revenue.

```sql
WITH Product_Total AS
(
    SELECT
        product_key,
        SUM(sales_amount) AS total_amount
    FROM fact_sales
    GROUP BY product_key
)
SELECT
    product_key,
    total_amount,
    ROUND
    (
        total_amount * 100.0
        / SUM(total_amount) OVER (),
        2
    ) AS revenue_contribution_pct
FROM Product_Total;
```

### What this query does

The CTE calculates total revenue for every product.

The window function calculates total revenue across all products.

Each product's revenue is then divided by the overall revenue to calculate its percentage contribution.
